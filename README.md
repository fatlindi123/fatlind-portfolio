# Fatlind Lubishtani — Portfolio

Personal portfolio for **Fatlind Lubishtani**, an AI Engineer / Software Developer based in Kosovo and a Computer Science student at University "Kadri Zeka".

The site presents selected work in AI engineering, software development, backend systems, LLM applications, and data analysis. Project showcases use small, custom CSS animations to explain each system's flow without relying on stock imagery or invented performance figures.

## Featured projects

- **[AnalyCode](https://github.com/fatlindi123/Analycode)** — Codebase analysis with Python AST chunking, RAG, pgvector, background indexing, deterministic security checks, and file and line citations.
- **[Enterprise-RAG](https://github.com/fatlindi123/Enterprise-RAG)** — A document question-answering application with a FastAPI backend and local Qwen 2.5 3B inference through Ollama.
- **[FlowForge AI](https://github.com/fatlindi123/AI-Automation-Workflow)** — A visual workflow automation platform with React Flow, execution logs, and configurable Groq and Gemini providers.
- **Punaks** — An AI-powered Kosovo job discovery and matching platform. **In Development.**

## Technology

- Next.js 13 and React 18
- TypeScript
- Sass modules and CSS animations
- Tailwind CSS
- Responsive layouts and reduced-motion support

## Run locally

Requirements: Node.js and npm.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Create a production build with:

```bash
npm run build
npm start
```
